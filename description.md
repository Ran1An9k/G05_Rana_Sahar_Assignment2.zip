# Insider Threat Detection Using User Behaviour Analytics (UBA)
The project entails a system for detecting insider threats within an organization through user behavior analytics.
* In other words:
You have data on employee activities (Login, Email, File Access, USB Usage, Web Activity),
and the task is to develop a Machine Learning model that identifies employees who may pose an insider threat compared to normal users.

## Problem Statement 
Insider threats originate from individuals with internal access privileges within the organization, such as:
  * An employee who steals data.
  * An employee who copies sensitive files onto a USB device.
  * An employee who transmits information outside the company.
  * An employee who accesses the system at unusual hours.
  * Traditional security methods may not easily detect such activities.
  * Therefore, we will employ:
  * User Behavior Analytics (UBA).
   to analyze user behavior and detect anomalous activities.
