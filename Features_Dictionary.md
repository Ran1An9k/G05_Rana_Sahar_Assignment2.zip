# CERT Insider Threat Dataset

| Feature | Description |
|---|---|
| User_ID | ID of the employee using this device. |
| Login_Time | Date and time of login. |
| Logout_Time | Date and time of logout. |
| Session_Duration | Duration of the session in seconds. |
| File_Access_Count | Number of times the user accessed files. |
| Website_Visits | Number of websites visited by the device. |
| After_Hours_Activity | Indicates activity outside regular working hours. |
| Threat_Label | Final categorization. |
